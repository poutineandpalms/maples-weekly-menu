# Maple's Weekly Menu

A weekly RSS feed of recipe picks, designed to be subscribed to in the [Mela](https://mela.recipes) iOS recipe app.

**Feed URL:** https://poutineandpalms.github.io/maples-weekly-menu/feed.xml

Paste it into Mela under Feeds → +. Each feed item links through to the source recipe page, and Mela extracts the full recipe (ingredients, steps, times) from the page's `schema.org/Recipe` structured data.

Hosted free on GitHub Pages. The feed is refreshed weekly.
